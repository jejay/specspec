# Explore rainbow parameters outside the graph application

Provide a small separate HTML/JavaScript tool for adjusting the rainbow palette
interactively. A final parameter set or palette that can be copied back to the
assistant is sufficient; directly generated CSS is useful if straightforward.
It should be easy to try different counts, saturation/lightness and hue ranges.
This does not ask for a palette editor integrated into the production graph UI.

Origin: the user's request to parameterize and inspect colors personally.
