# Preserve visible tangent-arrow strength at every supported scale

Compensate stroke width to at least 1.6 CSS screen pixels and arrow length to at
least 6 pixels, retaining ordinary world sizes at higher magnification. Compensate
Git dash lengths too. Direct side ports have 3-world-unit clearance. Ordinary cards
use full-height attachment distribution; circular ports use their specified chords.

Use a short straight departure and a horizontal tangent settling approach long
enough for the supported low-zoom head, currently 64 world units. Trim the line at
the filled head base so curve and triangle form a clean join. Preserve obstacle
corridors and directed reverse-history loops. Camera changes update the existing
edge appearance with the same world positions, native forms and canonical metadata.
