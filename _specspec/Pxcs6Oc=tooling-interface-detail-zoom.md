# Describe tooling interfaces through a companion detail zoom

Keep the actor-first overview and provide a separate accessible offline SVG that
opens the renderer-to-host message port, the host/agent-to-CLI subprocess contract
and the CLI-to-library in-process calls. Group the CLI facade and domain modules
within one per-invocation Python process and distinguish alternative Python
embedding in a caller's own process. Name the current functions, payloads, return
records, diagnostics and process controls at their actual boundaries.

Trace a native form edit through document overlays, editor input, a non-writing
before/after plan, native document application and sequence acknowledgement. Show
native Save as its own persistence action and summarize other view/operation routes.
Separate process success from graph validity and distinguish agent-owned process
controls from UI host queues, confirmations and native dirty-buffer guards.

This companion zoom lets readers follow concrete control and data flows without
turning the primary overview into an exhaustive module map. The artifacts describe
existing implementation contracts; keep their examples and source guide current,
inspect offline renders and verify their accessibility and local references.
