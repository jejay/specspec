# Visualize workspace and revision graph differences

Work alongside the host's Git integration. The default workspace graph shows its
difference from freshly resolved HEAD; users may also compare two selected commits.
Make node changes, changed relationships and filename-only changes understandable.

Color the headline and show a matching bottom-right A/M/D cue for added, modified
and deleted nodes, with R for a filename-only rename. Use configured host theme
colors and suitable standalone defaults. Semantic fills and linked-source impact
have independently explained meanings. Source-only changes have an informational
cue; direct node changes have their own Git letters.
