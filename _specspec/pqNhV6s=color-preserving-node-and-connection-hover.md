# Preserve node hover hues and strengthen colored connections

Only the neutral gray manifesto gets a white hover border. Other nodes retain
their semantic border hue upon hover, with stronger color emphasis (for example,
a yellow border becomes a strong yellow, not white). Apply this to compact and
expanded nodes, all semantic modes and revision states in both shared hosts.

Hovering changed, deleted or new nodes must make their incident colored curves
and arrowheads brighter AND more strongly colored, not washed out toward white
or a theme foreground. Preserve the existing relationship meanings, paired
heads, dash patterns and direction; node Git states do not invent new edge kinds.
Retain one-hop darkening, transient restoration and native editing/geometry.

Origin: the user's hover regression correction. The earlier manifesto request
never authorized white borders on other nodes. The all-card rule was an agent's
overgeneralization, not a user intention.
