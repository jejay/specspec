# Capture one identity-based per-view highlight set

Keep an ordered set of full node IDs shared by manual and spotlight-applied
highlights. Shift-click toggles membership; Ctrl/Meta+Shift removes it directly.
Consume chrome gestures without focus or camera movement; native controls retain
normal modified clicks. Anonymous new-node cards have no capturable identity.

Selection replaces the set with all submitted IDs, switches comparison and frames
available nodes. Paint surviving target or deleted base cards by identity, including
changed versions. Missing IDs remain in presentation state across refresh and
navigation. Flush preserves the editable set until explicit clear. Per-view
presentation stores IDs and the active spotlight identity rather than node text.

A modal freezes selected IDs and asks for a nonblank message of at most 500
characters, with Cancel and Create. The guarded host supplies current comparison
and native overlays. Validate selected IDs against both sides before atomic
metadata publication. Failures retain message and highlights for retry; creation
preserves drafts and camera and never saves a native document or managed form.
