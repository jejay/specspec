# Render the shared intrinsic graph world and guarded session

`graph-ui-common` supplies the local template, native DOM/SVG renderer, pure revision
metrics/layout/routing, camera, bounded CLI/discovery and guarded `GraphSession`.
All-parent earliest ranks feed a deterministic placement backbone; every displayed
link routes through clear corridors to actual shape ports. Camera updates adjust
edge and node paint while forms/world relationships retain their identity.

The shared port scopes state and messages by project/view and serializes authorized
operations with sequence/render acknowledgements. Adapters supply native host
facilities. Builds copy common bytes and offline pinned vendor/license notices.
Pure model/DOM/session tests and one real-host harness check relationship membership,
revision isolation, low-zoom paint, focus/drafts/caret, camera and rendering bounds.

Neutral curve/head ink uses the camera's bounded 70% to 35% strength while retaining
stroke/head dimensions and distinct diff/hover paint. Pure tests check its scale
function, DOM tests check camera propagation, and real-host probes inspect computed
curve/head colors across actual-size, intermediate and minimum magnification.

The real-host CDP harness keeps optional window sizing separate from foregrounding
and rejects closed/error transports promptly, clearing pending request timers.
Protocol/JavaScript errors and individual request timeouts remain failures; unit
tests exercise these boundaries independently of a real browser.

The separate camera owns a one-shot rectangle tool with Ctrl/Command hover arming,
latched primary-pointer dragging, a viewport-space band, inverse start-pose bounds,
click consumption and cancellation/disposal cleanup. A floating rounded icon HUD
exposes graph, contextual node and rectangle framing. Existing native controls and
Shift highlight gestures retain their event ownership. Rectangle framing permits
250% magnification; graph/node framing retains its 100% cap.

One inherited fill-progress property drives two-stage sRGB mixing toward the painted
border from each exact actual-size tint. Background fill transitions from 40%-to-16%
scale; ordinary edge ink transitions from 70%-to-16%, retaining 70%-to-35% strength.
Pure tests cover the independent scale functions and endpoints; DOM tests verify the
distinct onsets and camera propagation. Controller tests cover every drag direction,
modifier release, capture, cancellation, native boundaries, world/caret preservation
and synthetic Mac mapping. The early common installed-host canvas probe checks
dark/light/contrast fills at three scales, actual pointer capture/outside release,
contextual icons and editing. Complete installed suites combine these probes with
source, backchannel, native lifecycle, watcher recovery and persisted reload/revision
checks.
