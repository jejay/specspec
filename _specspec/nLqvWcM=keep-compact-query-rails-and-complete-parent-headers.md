# Keep compact query rails and complete parent headers

Use two-column tree indentation: pending siblings contribute │ and one space,
completed branches contribute two spaces. Branch markers ├─ and └─ touch the type
or reference arrow. Root content has two leading spaces. Prefixes preserve binding
text indentation, with plain multiline bodies retaining complete binding contents.

Each full header gives M/R/I and its filename stem, then every direct parent in
ascending case-sensitive full-ID order after @, separated by ·. Include the parent
under which the record is printed. The manifesto ends at its stem before comparison
status when present. Earlier shared occurrences remain short unexpanded pointers. Status suffixes
identify semantic node kind, contract-relevant linked-source changes and literal file change.
