# Use a gentle ordered rainbow and revision-status fills

Distance modes cycle an ordered violet-to-red rainbow. Type and comparison colors
reuse that table while retaining gently tinted cards. Git/Revision Status mode
uses colors close to added green, modified/renamed blue, removed red and source
impact amber. It also colors the manifesto by the selected comparison. Distance
and type modes use the neutral gray manifesto.
