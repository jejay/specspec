# Explain the current architecture without making the diagram canonical

Version the engineer-oriented architecture guide and self-contained SVG. Map
runtime ownership, refresh/reconciliation, managed transactions, native-document
planning/Save and source/test seams. Link actual repository files and the canonical
graph's reasoning. Explicitly distinguish saved Markdown DAG data, presentation,
Python domain rules and SDK adapters. Native Save can persist invalid text and is
not a managed writer transaction; Git snapshots/index validation are read-only.

The diagram is descriptive documentation, not a new architecture mandate, an
exhaustive call graph or a competing specification. Keep its current flow/paths
accurate as implementation changes. Render it offline for inspection and test
local links, accessible title/description and absence of scripts/remote resources.
No daemon, production agent connector, old-schema support or approval gate is added.

Origin: a revisable documentation choice resolving the unfinished engineering map,
under the existing self-hosting/shared-runtime intentions and backlog request.
