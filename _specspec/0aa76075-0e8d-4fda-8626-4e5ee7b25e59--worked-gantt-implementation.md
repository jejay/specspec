# Implement and audit the spec-aware planning example

example/gantt has an independent authoritative graph initialized before code,
explicitly fictional dialogue, actual CLI argv/stdin/fingerprint receipts, and real
spec-before-code stage pairs: 3ba86c0/8ac5676 (portfolio), f656942/f54142a (manual
personal dates), 95be927/660af26 (workshop forecast/baseline). Two guarded whole-branch
withdrawals replace 13/17 and 9/16 live nodes while retaining original identities,
bodies, parents, source references, and old runnable code. The final app graph has
44 nodes, 22 live and 22 withdrawn. Similar new scheduling reasoning has a new
identity; no approval statuses, scores, quotas, or nested repository are introduced.

The browser app runs from local files or a local static server without a build,
API/CDN, or external app requests. It offers validated weekday prerequisite
forecasts, earliest bounds, native editing, explicit baseline snapshots and date
comparisons, protected local storage, real file export, and previewed lossy v1 JSON
conversion. It excludes holidays/resources, accounts/cloud, and portfolios.
Twenty model tests and a real isolated Windows Chromium run passed; desktop/narrow
screenshots were inspected. Browser evidence covers timing/baseline, native caret,
cyclic drafts/deletion, literal text, actual file upload/download, import preview/
cancel/conversion, reload, corrupt/legacy storage, denied storage, and file launch.

The read-only verifier passed all three original spec/code pairs, predecessor/
ancestor ordering, fingerprints/CLI guards, an initially absent graph/code, and
unchanged old withdrawal semantics. A separate final audit stamps the actual last
code hash only after its commit exists. Four repository regressions check nested
context, full history, exact independent staged blobs in a disposable repo, and
withdrawn ancestry. All 72 Python tests, 85 editor tests, 20 app tests, Ruff, JS
syntax, graph validation, and the real app browser run passed locally. CI checks
both graphs, full history, app model, and installed Chromium; remote CI is not claimed.
Both exact indexes are validated before authorized commits; no hooks are installed,
no files are pushed, and unrelated logos/original intention/license stay unchanged.
This is a bounded educational example, not production scheduling, durable backup,
exhaustive manual/accessibility/platform/performance proof, or cryptographic proof
that a fictional dialogue constitutes a real user's review.


## Hash-free Markdown synchronization revision

The later manual-edit intention and separate hash-free/watcher conclusion supersede
all earlier API-2/fingerprint/stale-hash claims in this record. Current code uses
API/format 3, no managed_hash or fingerprint gate, and permits valid manual edits.
Original detailed test counts and packaged-host evidence above remain historical,
not claims of re-running every old package or platform against this revision.

GraphSession coalesces watcher events, retries failed reads twice, compares records
directly and validates current files before UI writes. Render sequence/full-membership
checks remain without fingerprint acknowledgements. Dirty drafts retain original
node records/caret/camera; unrelated changes permit saving, same-node overwrites ask
confirmation, and deletion/invalid files preserve copyable drafts. Invalid reloads
mark the last valid graph out of date and disable mutations until a valid reload.
VS Code watches directory/files; Electron's shared GraphWatcher also watches the
parent and reattaches after canonical-directory recreation. Optional configurable
polling defaults to zero/off and is disposed with sessions. No silent fallback,
universal event-delivery guarantee or adversarial race-free writes are claimed.

The independent Gantt working graph was migrated without changing body/relationship
semantics. Its original CLI receipts/Git commits are retained verbatim. The history
verifier now reconstructs records and compares actual contents directly; archived
hash strings are opaque receipt labels, not a current hash algorithm or edit gate.
See the separate current implementation record for source links and final checks.
