# Derive node newness and removal from Git snapshots

Store node identity, grammar, parent links, binding text and implementation source
hints. Derive additions, changes, renames, removals and source impact from the
selected Git comparison. The owner's review judgment and Git commit context explain
newness and reconsideration. Deleted files and their earlier explanations live in
predecessor Git trees, with reasons in commit messages.
