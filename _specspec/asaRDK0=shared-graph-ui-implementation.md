# Render the shared intrinsic graph world and guarded session

`graph-ui-common` supplies the local template, native DOM/SVG renderer, pure revision
metrics/layout/routing, camera, bounded CLI/discovery and guarded `GraphSession`.
All-parent earliest ranks feed a deterministic placement backbone; every displayed
link routes through clear corridors to actual shape ports. Camera updates adjust
edge paint while forms/world relationships retain their identity.

The shared port scopes state and messages by project/view and serializes authorized
operations with sequence/render acknowledgements. Adapters supply native host
facilities. Builds copy common bytes and offline pinned vendor/license notices.
Pure model/DOM/session tests and one real-host harness check relationship membership,
revision isolation, low-zoom paint, focus/drafts/caret, camera and rendering bounds.

Neutral curve/head ink uses the camera's bounded 70% to 35% strength while retaining
stroke/head dimensions and distinct diff/hover paint. Pure tests check its scale
function, DOM tests check camera propagation, and real-host probes inspect computed
curve/head colors across actual-size, intermediate and minimum magnification.
