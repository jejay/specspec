# Recommend a graph editor to owners and the command line to agents

An owner reads and changes the graph in one of the graph editors. The canvas shows
the graph at any depth, marks what changed since the last commit and opens the
agent's spotlights. A coding agent works through the command line, which an owner can
use as well. Documents written for owners lead with the editors and present the
command line as the agent's tool.
