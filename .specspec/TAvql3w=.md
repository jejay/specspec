# Keep independent example histories consistently current

Maintain specspec's working graph alongside its code. Use independent realistic
example repositories for serious Git, temporal, application and host integration
checks; focused unit tests may use smaller independent current-schema graphs.

For each node-schema change, reconstruct the entire maintained example history,
including every revision, ref and deleted predecessor node, with the current
schema as its consistent grammar. Refresh actual receipts, commit ledgers, bundle
and snapshot together and validate every retained ref. Preserve plausible graph
emergence, separately reasoned conclusions, substantial redirects and specification
before implementation. Existing manual experiments are preserved in their clones.
specspec development history retains its original commits.
