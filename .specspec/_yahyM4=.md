# Name canonical node files by their stable full identities

References use the full node identifier. Frontmatter defines identity, type and
parent identifiers; the Markdown body carries binding specification text.
Each node file is named exactly <id>.md, including the full trailing equals sign
before .md. Identity and path remain stable through body and parent edits.
Readable headings and binding text live inside the Markdown document.
