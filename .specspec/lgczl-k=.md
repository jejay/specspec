# Write the example's nodes as the shipped guide teaches

The example's manifesto holds intentions only: what people who plan work can do with the app, and that the repository is a worked example. Every other node is a conclusion from its parents, in plain present-tense sentences about the planner. An intention names no way of achieving it: the node on readable timing has the shared calendar axis as a node beneath it. The example's AGENTS.md is a short section about the example followed by the guide that init writes.
