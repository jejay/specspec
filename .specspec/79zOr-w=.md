# Discover canonical nodes and reserve .specspec/local for runtime state

The sole specification directory is project-root .specspec. Direct <id>.md files
retain full identities, node fields and source grammar. The exact local subtree
holds ignored runtime state, independently of the direct canonical node inventory.
Other non-node entries remain diagnosable. Symlink/file substitutions at either
directory boundary remain unsafe; validation never follows runtime data as nodes.

Backend discovery, raw/editor paths, Git snapshots, source roots, spotlights and
both hosts use this layout. The nearest canonical entry wins even if invalid.
Working self-documentation and every maintained Gantt revision/ref, earlier/deleted
node, actual receipt, ledger and bundle use the current contract. Existing local
experiments and unrelated development history remain preserved. The storage move
changes no node fields or application envelope grammar.
