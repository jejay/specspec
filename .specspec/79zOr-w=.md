# Discover and address canonical nodes in .specspec

The sole canonical directory is the project-root .specspec, with direct <id>.md
files and unchanged full identities, metadata, source grammar, node format 7 and
API 7. Human discovery follows the CLI, visual editor and document headings rather
than filename prose. The separate .specspec-local directory holds runtime state.

Backend discovery, raw/editor paths, receipts, missing-parent placeholders, Git
snapshots, source roots, spotlights and both hosts use this exact directory spelling.
Dot characters are literal in path validation; similarly named siblings and nested
noncanonical paths are distinct. The nearest canonical entry wins even if invalid.
Working self-documentation, source bindings and every maintained Gantt revision/ref,
earlier/deleted node, receipt, ledger and bundle use this same path contract.
Existing experiments and unrelated development history remain preserved.
