# Verify transport capabilities before enabling graph operations

A successful executable/version check alone does not establish compatible editing.
An older CLI can accept metadata-only update arguments while ignoring a body sent
with the current stdin convention. Guard this boundary before any read or mutation.

Use a hidden project-independent, input-independent startup probe that returns the
ordinary internal envelope and required feature identifiers for stdin bodies,
project initialization and nested local state. Both hosts check the envelope and
all required features with bounded output and deadlines. Missing executables/modules
produce installation guidance; unsupported probes, versions or capabilities request
an update rather than authorizing a potentially lossy save. No package installation
or public version-selection ceremony is introduced.
