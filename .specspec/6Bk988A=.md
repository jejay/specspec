# Show node text changes inside the binding editor

While editing a node, show its text changes inline in the same editing area, with
familiar VS Code-style change cues. Keep the target text editable and the original
text distinguishable at each changed passage. Provide the same experience in
VS Code and the standalone Electron window, preserving their save and undo owners.
