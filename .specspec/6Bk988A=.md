# Show the changes of a node's text inline in the field where it is edited

While the owner edits a node, the field that holds its text also shows how that text differs from the compared revision, with the change cues known from VS Code. The current text stays editable, and at each changed passage the original text can be told apart from it. VS Code and the desktop app offer the same field, and each keeps its own way of saving and of undoing.
