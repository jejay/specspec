# Name the command, extension and desktop consistently

The product is called specspec, in lowercase, in every maintained text and in the windows, titles and labels of the running applications. The Python distribution and the PyPI project are named `specspec`. The VS Code extension has the package name and the display name `specspec-vscode`. The Electron app has the product name and the package name `specspec-desktop`, and the names of its portable artifacts begin with `specspec-desktop`. Labels, generated examples and package descriptions use these lowercase names. The command identifiers of the extension, such as `specspec.openGraph`, and the Python import name `specspec` are stable interfaces. The artwork and the source files that the owner supplied stay byte for byte as supplied. The version numbers of the node format and of the protocol are details for machines, and an ordinary user sees them only when data or an installation is broken or incompatible.
