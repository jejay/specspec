# Name the command, extension and desktop consistently

Use specspec as the product name in maintained text and runtime chrome. The Python
and PyPI distribution is specspec; the VS Code package/display is specspec-vscode;
the Electron product/package and portable artifact prefix are specspec-desktop.
Keep command identifiers and Python imports stable. Preserve supplied artwork bytes,
original owner source artifacts and unrelated history; current labels, generated
examples and package descriptions use the lowercase names. Internal schema/protocol
numbers remain machine details, surfaced to ordinary users only for broken or
incompatible data and installations.
