# Keep the application header compact and contextual

Show the accessible SpecSpec brand symbol followed immediately by the live revision
label as one header group. Use an icon-only Refresh action with a tooltip and
accessible name. VS Code omits Open project from the graph header; its existing
Select Project command remains available. Electron retains the visible project
picker as well as its Project menu and Ctrl/Command+O, preserving discoverability
when no project is open. Other graph actions retain their behavior.

Below the toolbar, retain color legends and actionable diagnostics. Keep linked
source-file change totals and their file list in CLI revision reports; node-level
source cues and literal source previews retain their existing roles in the UI.
