# Keep the toolbar compact and show the compared revisions beside the symbol

The toolbar shows the specspec symbol alone, without a written name beside it; the symbol has an accessible name and is directly followed by the revisions that the view currently compares. Refresh is a button that consists of an icon, with a tooltip and an accessible name. In VS Code a project is chosen with the Select Project command. The desktop app keeps a visible project picker and opens it with Ctrl+O or Command+O as well. The desktop app removes the application menu bar: its controls for the graph, the project, the comparison and editing are in the shared page or are explicit shortcuts. Legends and diagnostics that the owner can act on stand below the toolbar.
