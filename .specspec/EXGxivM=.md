# Keep application chrome compact and contextual

Show the accessible specspec symbol immediately followed by live revision context.
Use an icon-only Refresh with a tooltip and accessible name. VS Code uses its Select
Project command. Electron keeps its visible project picker and Ctrl/Command+O.
The desktop has no application menu bar; graph, project, comparison and editing
controls remain in the shared UI or explicit shortcuts. Investigate the broken View
DevTools action for systemic implications without treating a replacement menu as
required functionality. Legends and actionable diagnostics remain below the toolbar.
