# Provide a seam for agent-workflow integration

Make the shared graph experience adaptable to Claude Code and OpenAI Codex
workflows. Preserve authoritative graph validation and mutation across adapters.
Treat each agent transport, credential boundary, authorization and lifecycle as
an independently specified integration decision before implementing its connector.
The current delivery scope consists of the CLI, editor and standalone adapters.
