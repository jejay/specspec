# Validate exactly the staged node files and compare snapshots of the graph by node ID

`check --staged` validates exactly the node blobs in the Git index, also for a file that is staged only in part. An entry in a merge conflict, an entry that is not a regular Markdown file directly in `.specspec`, a graph in an unsupported format version and an invalid graph each produce diagnostics. Hooks and CI that an owner has set up call `check --staged`. The owner manages the hook files and the chaining of hooks with ordinary Git tooling, under the hook policy that the repository already has.

Snapshots of the working files, of the index and of a commit are read in the current node format. A comparison matches the nodes of two snapshots by their full IDs. It returns the added and the removed nodes, for every changed node the fields that differ among text, parents and metadata, the node records of the base and of the target, and the links that were added or removed. The nodes that a change may affect are computed in both snapshots, from each changed node down to its descendants, so that a link which the change removed counts as well. A change of a source file reaches the implementation nodes that link the file in either snapshot and the requirements above them. This impact is counted per file and cautiously: a change anywhere in a linked file counts for every implementation that links it.

A base commit without a specification and a HEAD that has no commit yet each give an empty baseline, and any other revision that cannot be resolved is an error. Whether the graph is valid and whether the comparison is complete are two separate findings. For an invalid revision the comparison keeps the parent declarations it can read and the patches of the node text in LF lines. A document or a part of the history that is unavailable makes the analysis that depends on it incomplete, and the result says so. A read from Git leaves the checkout, the index, the branches and the refs to the user. `check --staged --sources` also judges how the source links map onto the staged files and whether Git keeps their anchored blobs.
