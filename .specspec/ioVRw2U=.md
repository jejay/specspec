# Rebuild the example's history with a repository script

A script in the example's history folder runs every recorded command again in a fresh repository, with the current command line and the recorded node IDs. It takes the app of each stage from the present bundle, makes the eight commits and their tags anew and replaces the tracked bundle, receipts, ledger, graph and AGENTS.md. A plan file with other node texts or links changes all stages at once. The verifier then checks the result.
