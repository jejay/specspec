# Emphasize incident pairs through transient pointer state

Delegate hover-capable pointer transitions through the viewport. Keep hovered ID
and last pointer position in renderer memory. Moving among controls inside one
card retains emphasis. Exit, blur, cancellation or touch clears it. Redraw/camera
movement re-hit-tests the pointer against the actual card.

Match immediate displayed parent/child IDs, including historical and draft links.
Toggle classes on existing curve/head pairs and paint incident pairs last. Normal
neutral links use theme contrast; colored links use hue-emphasizing paint. Restore
pair order/paint on exit. Keep geometry, dashes, world/camera and native fields intact.
The non-interactive SVG and native control events retain their usual boundaries.
