# Commit planning apart from implementation

Every change the agent makes to requirement nodes is a commit of its own under `Agent specspec changes: <description>`, including a conclusion it records in the middle of building. Code and implementation nodes go into commits with the project's own titles. The planning title therefore marks every commit that seals.
