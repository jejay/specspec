# Show a usable graph promptly and keep everything it means

A project and a node file open at low cost. The view presents the valid working graph promptly and says explicitly how far its comparison has loaded. Loading keeps everything the graph means: the current node format, the validation of the whole graph, a comparison with the current HEAD, the impact of source changes, the input and the text cursor in editor documents, independent cameras and the details of nodes in commits and of deleted nodes. Reads of Git, shared reads, derived caches and loading in phases all run through the Python tool, which is the authority, and through the shared renderer and session. The complete path of loading is measured, and the reports say what the measurements cover and what stays uncertain.
