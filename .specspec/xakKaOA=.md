# Share a blocking prerequisite and initialization screen across hosts

Probe the configured CLI before graph reads, including Electron before a project is
chosen. Use bounded shell-free execution on the appropriate workspace host. Missing
executables or Python modules produce an install-and-retry state; protocol mismatch
and other failures retain accurate diagnostics. Never infer absence of a graph from
an arbitrary read failure.

Inspect actual selected-directory entries through trusted host filesystem access.
An absent or empty/local-only real specification directory offers a centered
manifesto form and Initialize specspec button. The action is explicit, serialized,
project-scoped and trust-checked, invokes init with body stdin and refreshes current
graph context only after success. Concurrent graph appearance, dirty documents,
interrupted transactions and unsafe paths retain backend protections. Selection,
retry and errors stay actionable without stale graph mutation controls.
