# Keep a separate versioned Gantt product specification

Use an independent graph for the local Gantt app. Separate owner outcomes, solution
conclusions and terminal implementation mappings. Each product direction has an
agent-planned spec checkpoint before its runnable code. Major redirects delete
obsolete branches with reasons in commits and explanations retained in predecessor
trees. Positive binding text describes each stage's current desired product.

The tracked snapshot, actual CLI receipts and revision ledger are reviewable
artifacts; the complete bundle materializes a standalone repository for temporal
experiments. Optional STORY narrative is labeled as illustrative context. The app
is a bounded local browser planner with its own versioned JSON conversion contract.
