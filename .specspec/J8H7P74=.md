# Ship one current guide and preserve existing initialization inputs

Bundle a static AGENTS.md template with the Python distribution, independently of
this checkout or sibling drafting directories. It explains relationships, minimal
coherent nodes, shortcut-free ancestry, positive current bindings, bounded evidence,
owner/tandem/planning/implementation phases and current CLI workflows. Full IDs,
exact selected deletion, invalid-state repair, default replacement layout tolerance
and explicit Git authorization follow current tool behavior.

Init validates its initial graph before publication, creates a root AGENTS.md only
when no entry already occupies that name, and reports creation or preservation.
Existing bytes, directories and symlinks are left untouched, never merged or followed.
New instructions and canonical nodes share the lock, staged-byte journal and explicit
recovery boundary; publication never replaces a concurrent instruction file. Recovery
validates all known original/replacement/absence states before changing anything and
preserves external changes. The guide is not canonical graph membership. Init does
not stage, commit, install hooks or run agents.
