# Signal query source changes through their declared tracking contracts

Interpret source changes by the original reference class. Strict accepts reliable
relocation, outer-boundary/gap/outside edits and logical EOL equivalence while
protecting selected content. Expanding also accepts the internal/contained edits
that the shared resolver maps reliably, including partial deletions with a surviving
selection. Path-only whole-file references require a safe regular file, not stable
contents or readable lines; binary/LFS/large files need no spurious line warning.

Keep permitted changes unmarked in readable source rows and node source-changed badges. Metadata
reference additions/removals still show ref+/ref- independently. Exact byte/text/
position/anchor-relative outcomes remain raw comparison facts in JSON, alongside a
separate contract-change classification: same, changed or unavailable. Source
inspection/preview/check and shared conservative changed-file impact retain their
existing meanings; query does not promote raw file impact into a semantic source-changed cue.

Both reliably valid readings mean no contract-relevant change. A known valid/broken
transition is a change, including restoration. Stable missing links and identical
broken readings have no new change, though their existing issue stays visible.
Ambiguous/unavailable evidence remains explicit and never becomes a fabricated
change or unchanged result; identical file bytes and identical resolution facts can
establish no revision difference while leaving an existing mapping issue visible.
Compare every union declaration independently of membership as before.

The source-changed label marks known contract changes and their ancestors in both original graphs. Unknown
comparisons have explicit source-row hints and a structured completeness flag,
rather than a falsely certain source-changed/unchanged verdict. Query affected scope includes
contract effects; its separately named raw file-impact facts remain available for
broader review. Reads use the same bounded cached shared resolver and never
reanchor, rewrite metadata, fetch, stage or approve implementation meaning.
