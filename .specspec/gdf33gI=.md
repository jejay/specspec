# Spotlight the nodes an agent discusses

Whenever an agent discusses specific nodes with the owner, it also records a
spotlight on those nodes and says so. The owner opens the spotlight in a graph editor
and sees the nodes highlighted in their context, where a conversation offers only
node IDs. This holds in every phase: questions and proposed changes in tandem
planning, summaries after agent planning, and reports during implementation.
