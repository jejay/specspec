# Use the exact selected seven-color spectrum

The palette consists of these exact swatches in this order: `#bc82c9`, `#7e97e6`, `#1facce`, `#37b390`, `#92a64b`, `#ca8d3e`, `#dc7b7c`. A distance spectrum repeats the table.

The defaults of the playground are count 7, lightness 0.69, chroma 0.12, startHue 320 and endHue 20. They reproduce the seven supplied hex values with an empty `gamutReducedIndices` list. The swatches have exactly these bytes in production and in every export.
