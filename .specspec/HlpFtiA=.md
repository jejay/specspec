# Keep linear and logarithmic influence choices together

Absolute influence, Relative influence, Log Absolute Influence and Log Relative Influence are four separate Color by choices, and the selected one persists. The linear modes and their logarithmic counterparts are available side by side for direct comparison, in both graph editors.

A logarithmic mode applies log(influence) to the influence that includes the node itself, before normalization, so that a leaf has log(1) = 0. A linear mode subtracts one from the influence. A mode and its counterpart use the same reference, either the absolute range or the groups of nodes with the same maximum distance from the manifesto, the same continuous palette of red, yellow and green, and the same independent cues for Git and for highlights.
