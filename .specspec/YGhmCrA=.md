# Explain both spectra with outlined theme-paired README figures

Three README figures share one small planning graph. The first lays it out from
intention to conclusion, the second replaces a conclusion beneath an unchanged
intention, and the third marks a per-branch boundary between owner decisions and agent
conclusions. They use the editor's shape vocabulary (circle manifesto, rounded
requirement, square implementation), the brand neutrals and the Spectrum flow stops as
a left-to-right intention-to-conclusion axis. Deleted and added nodes carry the
editor's D and A cues; brand colors express spectrum position only.

Each figure is a self-contained SVG pair for light and dark surfaces, selected with
picture and prefers-color-scheme through absolute raw GitHub URLs that PyPI can also
display. Text is outlined from Manrope with pair kerning, so image contexts show the
brand type without loading fonts. SVG titles, descriptions and README alt text carry
the content for assistive technology. A repository script regenerates the figures
from the brand kit's font.
