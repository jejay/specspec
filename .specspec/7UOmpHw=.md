# Send owner intent back to agents through editable highlights

Both hosts let owners Shift-click node chrome to toggle a single highlight ink.
Ctrl+Shift-click or macOS Command+Shift-click removes one member. Clear highlight
clears the whole editable set. Native inputs and controls keep modified clicks.

Applying a retained spotlight produces the same editable highlights as manual
clicking. Owners can add or remove members while the original remains immutable.
Create spotlight from highlights asks for one message and captures the current
comparison. The agent reads messages, IDs, comparison, node statuses and advisory
workspace warnings through spotlight show. Native editing, drafts, ordinary
navigation and saving retain their independent behavior.
