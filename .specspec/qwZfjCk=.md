# Keep documentation to entry points, guides and procedures

The graph is this repository's specification and design record. Git commit
messages hold change reasons and evidence, and `--help` is the command reference.
Other Markdown files serve readers where they work: the README for GitHub and PyPI
visitors, CONTRIBUTING for contributors' setup, checks and maintenance procedures,
CHANGELOG for release notes, AGENTS.md files for coding agents, the extension README
as the editor guide, and the example's README. Each document stays short and points
to the graph for reasons. This repository's AGENTS.md is a short repository section followed by the shipped guide, in the order `specspec init` produces.
