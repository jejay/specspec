# Give the owner the same graph editor in VS Code and in a desktop window

The owner reads and edits the graph in VS Code or in a standalone window on Linux and Windows, and finds the same graph editor in both. The two share the behavior of the graph, the node forms with their drafts and text cursor, the comparison of revisions, a layout that is independent of the window size, navigation by pan and zoom, the emphasis on hover and the literal display of project text. In both, the Python tool is the authority on the graph and its rules.
