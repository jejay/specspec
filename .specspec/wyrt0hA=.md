# Give the structure review a phase section in the guide

The guide's phases include the structure review between owner planning and tandem planning. Its section says that an agent planning commit seals the graph beneath it and that the owner's hand changes since the newest one are open. It tells the agent to commit the uncommitted ones first as the owner wrote them, to hold the open nodes against the rules, to suggest and to leave the graph as it is. It says that an accepted suggestion is committed as the agent's planning while everything else stays in the owner's words, and how sealed nodes are treated. The section on agent planning names the accepted suggestions among the things the agent works from. Both sections include an open manifesto: the review reads its wording for conclusions, and planning puts what it finds into the summary. The review section is the guide's one place for that check: it says that a manifesto holds intentions only and that a conclusion in its wording, such as a layout or a technology that is not a given, belongs in a node beneath it.
