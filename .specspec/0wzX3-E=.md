# Keep every compared guide version as a file beside the quizzes

Each state of the shipped guide that a quiz result refers to stays in the repository as
a dated file beside the quizzes, together with the experimental variants that were
tried. The shipped guide itself is read from the package template, so a quiz measures
the text that init writes.
