# Explain ordinary commands with concise static terminal help

The help of the root, of every command and of every subgroup is arranged by task, uses ASCII characters alone and is the same in every project. Its explanations are short and give the purpose, the defaults, complete examples that are useful as they stand and the distinctions that matter for safety. The description of an option carries the detail of that option. Printing help reads neither standard input nor a payload nor a project.

In normal use a command runs in the directory of the intended project, like Git. The switches that select a project root and structured output are hidden controls for integrations: they appear in no help text, no example and no list of options, the help of the private transport command included. The internal versions of the node format and of the application protocol stay out of the help for agents and people and out of the readable headers of `query`, and an incompatible version produces a diagnostic that says what to do. Output into a pipe has the same form as output to a terminal.

Help explains the input from messages and from standard input, the difference between replacing a whole body and replacing passages, the replacement of the parent list, the flags that apply to a whole invocation, exact deletion and its consent, the validity of the final graph, recovery, the selection and the ancestors in `query` and the deliberate changes to source metadata. The everyday examples are free of transport mechanics.
