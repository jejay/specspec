# Give a node only to what is in force and could be concluded differently

Every node states something about the product that is in force and could have been concluded differently. Each node adds one such statement to what its parents say. Nodes that belong to one topic hang under a parent that states the intention they share. A conclusion that was considered and set aside is named in the agent's report, and a question that is open is named as open in the node it belongs to. An order of work guides the agent while it builds and stays in the conversation.
