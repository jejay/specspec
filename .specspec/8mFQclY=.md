# Give a node only to what is in force and could be decided differently

Every node states something about the product that is in force and could have been
decided differently: an outcome, a constraint or a choice. Each node adds one of these
to what its parent says. Nodes that belong to one topic hang under a parent that
states the purpose they share. An option that was not chosen is named in the agent's
report, and a choice that is open is named as open in the node it belongs to. An order
of work guides the agent while it builds and stays in the conversation.
