# Guide versions kept as files

`guides.py` resolves the name `shipped` to the package template and every other name to
a file under `tools/guide_quiz/guides/`. Three files are dated states of the shipped
guide: the one released with 0.0.1, the one of 2026-11-10 before the structure rules and
the one of 2026-11-11 with them. Seven files under `guides/experiments/` are variants of
the 2026-11-10 guide: five lines only, worked examples only, rule sentences, rule
sentences with a phase sentence or with a check sentence, rule sentences with worked
examples, and a long rules section.
