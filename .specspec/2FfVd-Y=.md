# Inspect the specification through one command

People and agents inspect the nodes, the descendants of a node, the ancestors that are its reasons and the literal text of a node file through one command. One command with one set of options is quick to learn. It reads the working files, the exact Git index and committed revisions, it reports the diagnostics of an invalid graph, and its literal text is what a deliberate repair starts from.
