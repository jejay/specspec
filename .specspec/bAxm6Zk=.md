# Describe specspec in terms of the product and its artifacts

The README, the agent guide and the editor guide state what specspec does in terms of the product and the artifacts that realize it, such as code, chapters, slides or media files. The README names several kinds of product a graph can specify and uses software, such as the planning app, as one example among others. It says how implementation nodes link artifacts: text files by line range or as a whole, any other file as a whole.
