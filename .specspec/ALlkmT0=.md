# Use the supplied optical symbol and launcher artwork

The selected optical icon, 24 units in size and leading from a circle through an S to a square, is imported unchanged for the shared header. Its alpha mask is filled with the foreground color of the editor, which gives a symbol in one ink that fits every theme. The supplied spectrum launcher tile of 512px is imported as the icon of the desktop app and of the extension package. The source paths and the SHA-256 digests of the imports are kept in this repository, so that builds and artifact checks work independently of the sibling branding workspace. The brand colors are separate from the colors that carry meaning for the graph, for Git and for diagnostics.
