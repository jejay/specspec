# Time limits in the unit-test scripts and CI jobs

The `test` scripts of the shared UI, the VS Code adapter and the desktop app pass
`--test-timeout=120000` to the Node test runner. Node 22 applies the limit to each
test file as a whole and reports the file as timed out; Node 24 applies it to each
test and names the test. The slowest file takes about 25 seconds on a CI runner.

In ci.yml the Python jobs end after 30 minutes, the desktop jobs after 20, the
extension jobs after 15 and the Gantt job after 10. The Python suite and the Gantt
example's tests have the job limit only; the real desktop suite also has its own
aggregate guard. The release build job in release-build.yml ends after 60 minutes.
