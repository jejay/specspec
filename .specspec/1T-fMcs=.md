# Make specspec straightforward to install and try

A newcomer can install specspec and try it on a project of their own. The command-line tool, the extension for the VS Code they already use and the standalone desktop app are three separate things to install, and a newcomer takes the ones they want. The documentation explains the prerequisites, the commands, upgrades and troubleshooting to a reader who knows nothing about how specspec itself is developed and tested. Every release says candidly what it contains and what it can do.
