# Make specspec straightforward to install and try

Release candidly from one source monorepo. People can install the global CLI,
build and install the extension into their ordinary VS Code, or build and run the
standalone desktop app. Explain prerequisites, commands, upgrades and
troubleshooting without requiring knowledge of the development harness. The VS Code
extension ships as a locally built VSIX. Building is separate from publishing,
signing, tagging and committing.
