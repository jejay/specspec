# Let a new owner start by initializing and talking to their agent

A new owner needs three steps: install the CLI, run init with one sentence about the
project, and tell their coding agent what they want. The guide that init writes leads
the agent through planning, building and reporting from there, so the owner can begin
at the delegated end of the range without learning the graph first. The agent's
reports and the graph show where control can be taken: a node to read, a conclusion to replace, a branch to specify by hand.

The README carries this as a quick start ahead of its explanation of the concept.
