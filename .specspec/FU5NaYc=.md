# Deepen and reconcile the specification when asked to plan it

A request to draw/change the graph enters agent planning. Read the existing graph,
owner input, saved working/index state and usable historical/tandem context. Preserve
owner changes first. Use specspec add/update/delete tools to build the best precise,
implementation-mature graph justified by the available understanding. Complete the depth that building needs, and fill breadth where the owner evidently left a gap for the agent. Keep meaningful
conclusions separate and explain their intention relationships.

Inspect deletion scope and reconnect retained children deliberately when consolidating
reasoning. Validate the complete intended graph and exact staged source/index state.
The planning request also authorizes committing the result as
`Agent specspec changes: <description>`. Every other commit follows the project's own rules. Summarize changed intentions, choices,
implementation gaps and affected nodes. Schema-breaking history
is handled with current workspace evidence and independent compliant fixtures.
